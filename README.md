# vanilla-ui-patterns

Clean, accessible UI patterns written in plain HTML5, CSS3, and ES6+ JavaScript — no frameworks or external runtime dependencies.

## Patterns

- **Native Modal (`<dialog>`)** — Uses `showModal()`, `::backdrop`, and `closedby="any"` with a pointer-bounds fallback.
- **Accessible Tabs** — Keyboard-friendly `role="tablist"` / `aria-selected` switching.
- **Deferred Form Validation** — Uses `:user-invalid` and `:user-valid` so errors only appear after interaction.
